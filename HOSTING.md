# Hosting and domain options

Checked 2026-10-28. CE Link is a static, single-file application, so it needs no server process, database, API service, or paid hosting plan.

## Free hosting

The live site is https://silo555.github.io/ce-link/ . It is hosted on GitHub Pages from the public repository's `main` branch. GitHub Pages is available for public repositories on GitHub Free and supports custom domains. The default github.io URL costs nothing.

Source: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

The downloadable HTML also continues to work offline in compatible browsers. A custom domain does not change calculator USB permissions or driver requirements.

Promotions, availability, premium classification and registry pricing may change before checkout. These are the lowest useful options found in this check, not a guarantee of the lowest rate across every registrar and extension.

- Spaceship price table (including ICANN fees): https://www.spaceship.com/domains/
- .shop rates: https://www.spaceship.com/domains/gtld/shop/

Vercel's exact-name quotes were: ce-link.shop $2.99 registration / $38.39 renewal; ce-link.click $1.99 / $11; ce-link.link $7 / $7; ce-link.xyz $1.99 / $13. That makes Spaceship's advertised promotional rates lower for the first two, subject to checkout verification.

The cheapest first year found was `ce-link.shop`; `ce-link.click` suits a browser utility better; `ce-link.link` has the lowest verified ongoing price among the three. Keeping the github.io address is the only zero-cost option here.

A domain can be registered separately and connected to GitHub Pages; buying registrar hosting is unnecessary. GitHub's custom domain guide: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages
