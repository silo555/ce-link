    Before connecting

    • Turn the calculator on and open its home screen.
    • Use a USB data cable.
    • Close TI Connect and other calculator tabs.

    Use desktop Chrome or Edge. USB access depends on your computer’s drivers and school policy.

    Connection help & supported files

    Browser & USB access

    Use desktop Chrome or Edge. Firefox and Safari don’t provide native WebUSB. If the downloaded HTML can’t access USB, try the online version. School policy can still block access.

    Windows connection problems

    Windows may need an existing WinUSB driver for the calculator. HTML cannot install drivers. Close TI Connect, try another data cable, or ask school IT if the device cannot be opened.

    What you can send

    Programs and AppVars, including groups containing only those types, with ASCII letter/digit variable names. Flash apps, operating systems, and direct text/Python conversion are unsupported.

    If a transfer stops

    Check the calculator for partial results before retrying. Files already sent remain on the calculator. Clear the queue and re-add an uncertain file to send it again.

    Experimental software. Physical calculator transfer has not yet been verified for this build.
