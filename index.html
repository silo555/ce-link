    Connection help & supported files
    • Use desktop Chrome or Edge. Firefox and Safari do not provide native WebUSB support.
    • If USB is unavailable from a downloaded file, try the HTTPS version. A managed computer can still block USB; this tool cannot change school restrictions.
    • Windows may require a WinUSB driver already associated with the calculator. HTML alone cannot install a driver. Ask school IT if the calculator cannot be opened.
    • A charging-only cable will not work. If the picker is empty, try another data cable or port.
    • Supports programs and AppVars, including groups containing only those types, with ASCII letter/digit names. It does not install Flash apps or operating systems, convert text/Python/ZIP files, or make incompatible programs run on your OS.
    • If a transfer stops, check the calculator for partial results before retrying. Already sent files remain on the calculator.
